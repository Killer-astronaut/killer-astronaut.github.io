LUMEN IS IN DEVELOPMENT

A private reading companion for turning imported PDFs into listenable chapters with local library storage and Apple speech voices.

In development Support details
Imported files stay local No account required Real-device testing underway
Current focus

Testing PDF import, OCR failure states, playback, interruptions, and storage behavior on real devices.

What is being built

Listen to the documents you bring.

Lumen is being built for private document listening, with careful attention to import errors, playback controls, and local storage.

01 - Import

Bring a PDF from Files.

Lumen reads selectable text when available and handles scanned or malformed documents with clear states.

02 - Chapters

Break long files down.

Imported documents become a local library with chapters, progress, and playback controls.

03 - Playback

Use system voices.

Playback uses Apple speech voices and system audio behavior instead of a developer-run audio service.

04 - Private

No cloud library.

Documents, covers, settings, and progress are intended to stay on the user's device.
