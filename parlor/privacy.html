Privacy Policy

Last updated July 7, 2026

Parlor does not use developer accounts, advertising SDKs, analytics SDKs, or third-party tracking.

Game data

Prompts, answers, votes, scores, table codes, and local player names are used to run the game. The app is designed to keep this information on participating devices rather than sending it to a developer service.

Nearby play

If nearby table features are enabled, Parlor may use the local network so devices in the same room can discover or join a table. This traffic is for gameplay between participating devices.

Data collected by developer

None. Parlor is being built without developer-run accounts, ads, analytics, or a cloud player database.

Contact

Privacy questions can be sent to hello@getlokei.com.
